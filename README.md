# Tool Sharing App

**Interactive link: https://www.figma.com/design/36wKuqT5f6BwhE120iGSmv/Coummunity-tool-share?node-id=0-1&t=m20VLK8dweCipGoR-1**

A simple app for sharing and borrowing tools.

## Pages

- **Home** — Browse available tools.
- **Tool Details** — View a tool and request it.
- **Dashboard** — View your listings and borrowed tools.

## Features

- Search tools
- List tools
- Request tools
- Track borrowed tools
- View tool status
